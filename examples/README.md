# Examples

Before/after transcripts for the skills on `main`. Each file is one fictional coding moment: the reply without the skill, then the reply with it.

- [`chirp.md`](chirp.md) — a modal stuck under a promo bar, restated in plain language.
- [`senpai.md`](senpai.md) — cursor pagination on `GET /orders`, taught as a pattern.
- [`challenge.md`](challenge.md) — `POST /invoices/:id/pay`, checked for double-pay and a client-supplied amount.
- [`prove-it.md`](prove-it.md) — empty customer search, checked with tests and `curl`.
- [`drift.md`](drift.md) — a notifications worker whose README, config, and consumer disagree.

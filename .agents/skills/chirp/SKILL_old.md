# Chirp

Distill your previous response. Do not rewrite the whole thing more simply.

## Goal

Identify the **single most important idea** the user needs to understand.

Explain that idea like a knowledgeable friend over coffee.

Delete everything that can reasonably be learned later.

## Output Rules

For a long or technical previous response, you MUST:

- Stay under 300 words.
- Use no more than 3 short sections.
- Use no more than 2 examples.
- Omit advanced details, edge cases, internals, related features, and optional techniques.
- Never reproduce the original outline.
- Never explain every topic from the original response.
- Use jargon only when necessary, and immediately explain it.
- Preserve details only when removing them would make the answer inaccurate or unsafe.

Before answering, ask yourself:

**"What can I delete while still making the main idea click?"**

Then delete it.

End with:

**Basically:** [the main idea in one or two sentences]
